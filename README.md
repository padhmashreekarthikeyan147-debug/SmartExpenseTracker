# Smart Expense Tracker

A Django-based Smart Expense Tracker that helps users manage expenses, monitor budgets, and analyze spending through interactive dashboards.

## Features
- User Authentication
- Expense Management (CRUD)
- Dashboard Analytics
- AI-based Category Prediction
- Budget Management
- Dark Mode
- CSV & PDF Export
- Responsive Bootstrap UI

## Tech Stack
- Python
- Django
- SQLite
- Bootstrap 5
- Chart.js

## Installation

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
